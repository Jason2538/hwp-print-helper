# 인쇄 도우미

한글(.hwp) 파일 — 배포용(읽기 전용) 문서 포함 — 과 PDF를 불러와서 용지 크기에 맞춰 자유롭게 인쇄하는 웹 프로그램이에요.
(예: B4 문서를 A4에 잘리지 않게 맞춰 인쇄)

- 용지에 맞춤 / 배율 직접 입력 / 여백 조절 / 쪽 범위 / 모아찍기
- 파일은 **브라우저 안에서만** 처리돼요. 어디에도 업로드되지 않아요.
- 한글과 완전히 같게 그리는 것은 아니에요. 수식·일부 도형은 다를 수 있으니 인쇄 전에 미리보기를 확인하세요.
- 암호가 걸린 문서, DRM 문서, .hwpx는 열 수 없어요.

## 파일 구성
- `index.html` — 실제로 쓰는 단일 파일 (PDF 엔진 포함)
- `src/` — 한글 파일 읽기(`core.js`), 그리기(`render.js`), 수식(`equation.js`)
- `template.html`, `build.js` — `index.html`을 만드는 틀과 빌드 스크립트
